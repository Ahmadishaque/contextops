# Git Workflow

This project follows a production-style Git workflow.

## Branches

- main: stable, demo-ready branch
- feature/*: feature development
- fix/*: bug fixes
- docs/*: documentation changes
- chore/*: maintenance changes

## Commit Style

Use Conventional Commits.

Examples:

- chore: initialize project scaffold
- feat(api): add healthcheck endpoint
- feat(retrieval): add Qdrant vector search
- fix(agent): handle empty context safely
- docs: update architecture overview
